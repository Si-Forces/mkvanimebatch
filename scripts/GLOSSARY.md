# Home-path Guard

Terms for the contributor workflow that protects home directories from accidental publication.
The current behavior is documented in [CLAUDE.md](CLAUDE.md).

## Language

**Home identity**:
A home directory protected by the home-path check in the checking environment. Different home
directories are separate identities even when they belong to the same person.

**Home spelling**:
A textual representation of a home identity, such as path notation or a dashed name. Different
spellings can represent the same identity.

**Prepared PR body**:
The complete pull request description selected for publication before creation or a body update.
